# OYNA — 9 ойыннан тұратын басқатырғыштар клубы

HTML5, CSS3 және JavaScript негізіндегі mobile-first ойын. Қазақ, орыс және ағылшын тілдері, таңдаулы ойындар, жетістіктер, дыбыс әсерлері, Web Audio әуені және жеңіс конфеттиі бар. Әр ойынның 1–1000 деңгейі тұрақты seed арқылы жасалады. Қонақтың прогресі мен баптаулары браузердің localStorage қоймасында сақталады. Бір деңгейден шыққан ойыншы сол деңгейден қайта бастайды; аяқталмаған тақтаның жеке қадамдары сақталмайды.

## Іске қосу

Node.js 24 қолданыңыз:

```sh
npm ci
netlify dev --port 8889
```

Браузерде http://localhost:8889 ашыңыз. Генераторлар мен ойын ережелерін тексеру: `npm test`.

## Аккаунт және бұлттық прогресс

Бұл нұсқада платформа талаптарына сәйкес Firebase Authentication / Firestore орнына **Netlify Identity + Netlify Database** қолданылды. Google провайдері Identity баптауында қосылғанда, «Google арқылы кіру» жұмыс істейді. Қосылмаған жағдайда түсінікті хабарлама көрсетіледі және қонақ режимінде ойнауға болады. Google аккаунтымен толық кіруді тексеру үшін провайдер қосылып, сайт жарияланған болуы керек.

Деректер сызбасы `db/schema.ts` файлында. Миграция `netlify/database/migrations/` ішінде дайын; Netlify оны жариялау кезінде автоматты қолданады. Қолданба дерекқор құпияларын клиентке шығармайды. Сервер Identity токенін тексеріп, тек сол ойыншының прогресін оқиды және жаңартады. Екі құрылғыдағы прогресс ең жоғары аяқталған деңгей бойынша біріктіріледі. Ұпай аяқталған деңгейден есептеледі: әр деңгейге 100 ұпай. Бұрын өткен деңгейді қайта ойнау қосымша ұпай бермейді. Офлайн өзгерістер келесі қосылуда қайта жіберіледі.

Google провайдерін Netlify жобасының Identity → External providers бөлімінде қосыңыз. Өз Google OAuth клиентіңіз қолданылса, Identity көрсеткен callback URL-ді Google Cloud консоліне енгізіңіз. Тіркелгі құпияларын кодқа немесе репозиторийге қоспаңыз.

## Android APK / AAB: Capacitor

Android Studio, Android SDK және JDK 21 қажет. Capacitor конфигурациясы дайын: `capacitor.config.ts`, appId: `kz.oyna.puzzles`.

1. Веб-нұсқаның файлдарын дайындаңыз:
   ```sh
   npm ci
   npm run build
   ```
2. Android жобасын бір рет жасаңыз:
   ```sh
   npx cap add android
   ```
3. Веб-файлдар мен плагиндерді көшіріп, Android Studio-ны ашыңыз:
   ```sh
   npx cap sync android
   npx cap open android
   ```
4. Телефонда USB debugging қосып, Android Studio-да құрылғыны таңдап, Run басыңыз. Эмулятормен де тексеруге болады.
5. Сынақ APK: Android Studio → Build → Build App Bundle(s) / APK(s) → Build APK(s). Немесе:
   ```sh
   cd android
   ./gradlew assembleDebug
   ```
   Нәтиже: `android/app/build/outputs/apk/debug/app-debug.apk`.
6. Google Play үшін Build → Generate Signed Bundle / APK → Android App Bundle таңдаңыз. Өзіңіздің keystore файлыңызбен қол қойыңыз. Keystore мен құпиясөзді репозиторийде сақтамаңыз.

Код өзгерген сайын `npm run build` және `npx cap sync android` орындаңыз. Ойын Android-та портреттік бағдарды плагин арқылы сұрайды. Қонақ режимі интернетсіз де жұмыс істейді; алғашқы жүктеуде интернет болмаса, қаріп жүйелік қаріппен ауысады. Ойын суреттері SVG ретінде бірге жеткізіледі.

### Android-та Google арқылы кірудің шегі

Осы бастапқы нұсқаның аккаунт пен бұлттық сақтау жолы жарияланған веб-сайтта іске асады. Жергілікті файлдардан жұмыс істейтін Capacitor WebView-да Google OAuth және бұлт API-і әзірге қосылмаған: аккаунт батырмасы жарияланған сайтты сыртқы браузерде ашады. Сыртқы браузердегі аккаунт пен прогресс WebView-ға автоматты берілмейді. Толық native Google кіруі үшін жүйелік браузердегі OAuth, тексерілген Android App Links және қауіпсіз сессия алмасу ағынын бөлек қосу қажет. Google OAuth-ты WebView ішіне тікелей ашуға болмайды.

## Құрылым

- `src/main.js` — экрандар, сенсорлық басқару, сессия және прогресс.
- `src/engine.js` — тоғыз ойынның детерминдік генераторлары мен ережелері.
- `src/i18n.js` — үш тілдегі мәтіндер.
- `src/icons.js` — жергілікті SVG иллюстрациялар.
- `src/style.css` — телефон, планшет және үлкен экран дизайны.
- `netlify/server/index.ts` — қорғалған прогресс API-і.
- `db/` — Drizzle моделі мен клиенті.
- `tests/engine.test.js` — 1000 деңгей бойынша генератор мен ереже тексерулері.

APK жинағы бұл ортада жасалмады; Android Studio және нақты Android құрылғыларындағы тексеріс әлі қажет. Автоматты тесттер құрылғыдағы толық тексерісті алмастырмайды.
